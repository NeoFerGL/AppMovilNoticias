# 📰 AppMovilNoticias

## 📱 Descripción del Proyecto

**AppMovilNoticias** es una aplicación móvil híbrida desarrollada con **Ionic Framework 6** y **Angular 16**, que permite a los usuarios consultar noticias en tiempo real gracias a la integración con la API de **NewsAPI v2**.  
Su diseño **mobile-first** garantiza una experiencia óptima en dispositivos móviles.

---

## 🛠️ Tecnologías Empleadas

- **Ionic Framework 6**  
- **Angular 16**  
- **NewsAPI v2**  
- **TypeScript**  
- **HTML5**  
- **SCSS**
